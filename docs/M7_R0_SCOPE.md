# M7-R0 Scope Boundary / M7-R0 범위 경계

R0 validates **authority/data contracts only**.

In scope:
- automation material schema;
- source-bound edit candidate schema;
- authority result schema;
- stable automation lock schema;
- cross-field contract validation;
- valid/invalid fixtures;
- deterministic contract evidence.

Out of scope:
- accepted Blueprint storage/migration;
- Project mutation;
- Preview generation;
- Accept/Discard runtime;
- Browser automation UI;
- Music IR automation lowering;
- audio rendering of automation;
- VST/AU/CLAP or DAW integration;
- external automation reverse mapping;
- real-time control;
- human/perceptual evidence.

No out-of-scope capability may be inferred from R0 validation.
